# 《诡仙录》人物设定文档

> 版本：因果宿命升级版  
> 类型：中式民俗恐怖 + 东方诡仙 + 宿命因果律 + 存在主义哲学  
> 核心精神：人以身为饵，饲诡登阶。力量即污染，篡改即代价，因果轮回不由人。


## 一、主角：沈渊

### 1.1 基础信息

| 项目 | 内容 |
|------|------|
| 姓名 | 沈渊 |
| 别名 | 纸骨沈渊、忘川阁主、半步真君、因果守望者 |
| 年龄 | 出场约二十余岁，历经棺中沉睡与因果逆流约五百余载 |
| 身份 | 书肆掌柜 → 玄门外围弟子 → 忘川阁主 → 纸扎城域主 → 诡仙 → 劫仙 → 半步真君 → 因果守望者 |
| 境界 | 见诡 → 饲诡 → 化诡 → 掌诡 → 炼诡 → 诡仙 → 劫仙 → 半步真君 |
| 种族 | 凡人 → 纸骨墨身（第四卷折身为纸后） |
| 特色 | 贪生怕死但选择勇敢，天生契合因果大道（强改命数），千百世前世残魂共存 |

### 1.2 外貌与性格

**外貌**：
- **初期**：寻常书肆掌柜，面容温润清秀，唯右手掌心有一道细长裂缝，后开裂为重瞳天眼。
- **纸化后**：肉身骨骼化为青篾，血肉化为宣纸，在月光下呈现出淡墨水墨般的水晕纹路。掌心天眼散发幽光。
- **半步真君**：身周因果丝线缭绕，身形介于存在与虚无之间，面容常在不同前世面容间幻化。

**性格**：
- **表象**：懦弱、贪生怕死、斤斤计较，生平最爱将世俗的悲剧话本强行修改为“大团圆结局”。
- **骨子里**：对“生路与结局”有着病态的执念——绝不接受天道格式化清理、众生被抹去的必死结局。善良却冷静狠辣，一旦决定反抗，可用最疯狂的手段将敌手拉入因果孽海。
- **弧线成长**：起初为求自保逃避因果残页的死劫；中期在前世的惨死残魂与纸扎城纸人们的执念中觉醒，主动承担代偿代价；后期看透天地大劫真相，选择永镇渊界守护众生的一线生机。

## 二、女主：纸鸢

### 2.1 基础信息

| 项目 | 内容 |
|------|------|
| 姓名 | 纸鸢 |
| 别名 | 纸鸢投影、因果守望者（本体） |
| 身份 | 纸扎城第一个纸人 → 见诡修士 → 幻化真人 → 天道因果守望者 |
| 境界 | 纸人身 → 见诡 → 饲诡 → 化诡 → 守望者形态（特殊） |
| 种族 | 纸灵 → 真人（第四卷） → 天道法则化身 |
| 特色 | 唯一在诞生之初便知晓自身是纸人的存在，执念是“在宿命闭环中拥有一场自主的选择” |

### 2.2 外貌与性格

**外貌**：
- **纸灵形态**：宣纸折叠的少女，五官由文曲淡墨勾勒，唯美而带有一丝冷洌。
- **真人形态**：由龙鳞、真阳血熔炼出的有血有肉之躯，但皮肤极白，隐带干燥宣纸的温热感。
- **守望者形态**：化为天道源头一团纯净的因果光芒，中心隐现断线风筝的轮廓。

**性格**：
- **外在**：坚韧、温婉，因深知自身是文曲真君随手点化的纸人，带有一种天生的宿命疏离感。
- **内在**：极度渴望“选择的权力”——宁可面对真实的死亡，也不愿活在被安排好的纸面定数中。她绝非依附于男主羽翼下的花瓶挂件，而是在关键节点展现出极其强大的破局意志（如第三卷折出不存在的门拉回沈渊、终卷主动选择化为轮回的一部分）。她坚信：“既然我是被落笔画出的，那我也拥有停笔、落笔的自由。”
- **与沈渊的执念**：她是沈渊在千百世惨死前世记忆折磨下唯一的清明锚点；而沈渊对她的承诺，是她在这冰冷宿命网中开辟“真人生”的唯一动力。

**目盲叙事功能（第四卷至第八卷）**：
> 化为真人的代价是双目失明。失明不是能力的削弱，而是**感知方式的转变**：她用纸人本能感知世界——能感受因果波动的方向、墨香的浓淡层次、沈渊靠近时独特的纸骨摩擦声与温度。她通过触摸笔迹来"阅读"，通过感受墨水温度辨认沈渊的法牒。  
> **最重要的叙事意义**：她是全书唯一一个**看不见沈渊外貌变化**的人——白发加深、纸骨透明、身形越来越接近虚无，这一切她都感知不到。她感知到的沈渊一直是他的"气息"和"温度"，而非外貌。因此，当所有人都在用眼睛目睹他消失时，她是唯一一个始终感知到"他还在"的人，这让她成为沈渊最后的存在锚点。  
> **视觉恢复的情感峰值**（第八卷·本体与投影合一）：恢复视力后，她第一眼看到的是沈渊——此刻要与第四卷化人时"第一次看不见他"形成首尾呼应。她终于能看见他，看见他白发，看见他半透明的纸骨身，看见他站在那里笑着说"你总算能看见我了"——而这是她送给这段执念的最后一眼，因为之后他即将永镇渊界。

## 三、反派与镜像：不同抉择的前世沈渊

由于天地因果死循环运转了五千万年，主角在无数次历史轮回中曾做出过不同的抗争，这些前世在因果扭曲下呈现在酆都废墟中。

### 3.1 真君沈渊（融合派）
- **来历**：某一次历史轮回中，沈渊为了避劫，选择将所有支线前世惨死残魂强行吞噬融合的变体。
- **状态**：完整真君果位（已失去凡人意志，成为绝对理性的法则化身）。
- **作风**：冷酷地认为应当主动清洗、删除世间不稳定的气运因果分支，以维持世界的微弱苟活。
- **结局**：被主角沈渊的凡人意志打动，和解后成为酆都废墟中“前世怨魂社区”的守护人。

### 3.2 换命师沈渊（交易派）
- **来历**：某一次历史轮回中，沈渊为了保命，拒绝前往纸扎城直面清明雨，而是隐匿在落星镇成立换命师组织。
- **状态**：劫仙境（因果线被交易大量反噬，左臂因代偿彻底透明化）。
- **作风**：极度精于算计，认为天地万物皆可作为代价进行命运交易。
- **结局**：被主角的舍身之道稳定了其即将崩溃的存在，失去换命权柄后，在纸扎城文曲塔下平静地担任一名图书管理员。

### 3.3 “未来死尸”沈渊
- **来历**：来自被天地无量量大劫彻底格式化清零后的废墟未来。
- **状态**：肉身已化为干尸，但执念被困在因果谱残页中寄信给过去。
- **作用**：向第一卷的沈渊发送死劫警示，促成这一世沈渊的因果觉醒，形成闭环。

## 四、核心配角

### 4.1 腹中旧人（胃里的老道士）
- **来历**：沈渊在前一次因果轮回中改命失败的残魂，化为因果结晶流失在落星镇。
- **性格**：唠叨、极其悲观、嘴硬心软。
- **凡心执念**：年轻时改命失败前，曾答应落星镇一个卖豆腐的凡人女子，带她去看纸扎城的黄昏。此执念在前期常以老道士梦呓般的胡话浮现，直至第八卷牺牲时，沈渊才明白那是他仅存的凡俗温柔。
- **日常互动机制**：吞下后胃部异化为法理熔炉。老道士作为主角的"因果死账缓冲区"，每天睡前必须与沈渊进行一次神魂同步的"三个怪问题交互"（如"你今日最想杀的人是谁"）。同步成功，老道士便能替沈渊分摊并阻隔死账的恶脓利息；若回答失败或拒绝回答，老道士的因果屏障失效，黑脓死账就会溢出灼烧沈渊的灵台。
  - **沉默阶段（第五至七卷）**：随着卷数推进，老道士因替主角分摊了太多的天道黑脓，神魂被严重侵蚀、渐渐趋于机械与木讷，逐渐保持沉默不再提问。此阶段死账缓冲由两条机制共同维系：一是老道士残魂本身仍在，哪怕不提问也如同一块沉默的海绵，被动吸收小量死账；二是沈渊与纸扎城的"因果血契"提供额外的分摊缓冲——城池居民的信念如同无数细线将死账分散稀释。老道士完全沉默是角色弧线终章的预兆，写作时可利用其"沉默到了几天"作为张力计量器。
  - **牺牲之后（第八卷）**：老道士自愿冲出承受大道格式化后，缓冲区彻底消失，死账将直接溢出灼烧沈渊灵台。此阶段沈渊依靠"与城池的因果血契"作为唯一残余缓冲，每次使用至宝都如同在灼伤中硬撑，制造强烈的生死压迫感。这也是终卷沈渊选择"重开六道、停笔让位"而非继续硬扛的根本动力之一。

- **作用**：作为伴生诡寄生在沈渊的胃里。他冷冷地嘲讽沈渊的挣扎，在关键时刻燃烧自身残魂为沈渊模拟死劫生路，第八卷最终牺牲以助沈渊合道（后在重开的六道轮回中复活）。

### 4.2 陈舟
- **来历**：忘川副阁主，陈念的先祖。
- **定位与特质**：笨拙、沉默，武将式的绝对忠诚。在行动上贯彻沈渊的所有指示。他敬重纸鸢，但视其为“未来的阁主夫人”而刻意保持敬畏的社交距离。
- **特色**：诡相为“因果铁壁”，在纸扎城坚守两百年抵御玄门，如同一面永不塌陷的城墙，最终战死，葬于英雄墓。

### 4.3 苏灵儿
- **来历**：逃离玄门的见诡女修，忘川的情报枢纽。
- **定位与特质**：细腻、敏感，善于洞察他人情绪。时常指出沈渊自己都未曾察觉的心声。把纸鸢当作亲妹妹，教她学习凡人的生活细节（如女红、梳头）。
- **特色**：诡相为“情绪残影”，曾因污染建立遗忘教被解救。晚年因长时间使用灵视而严重超载，平静坐化，留下一颗凝聚了毕生情感记忆的情绪晶石，葬于英雄墓。

## 五、古天庭真君执念（血字与墨字）

残页上浮现的评注笔迹，实为崩溃纪元中陨落的两位真君附着在法牒碎片上的因果残响。

- **朱红血字 —— 兵燹真君**
  - **前世身份**：古天庭执掌兵祸、灭绝与宿命判决的“兵燹真君”。
  - **特色**：极端的宿命论拥护者。笔迹如干涸的血痕，永远以残酷、毒舌的字眼嘲讽沈渊的反抗，坚信大劫无可阻挡，逆天改命只会引来更凄惨的代偿。
- **焦黑墨字 —— 文曲真君**
  - **前世身份**：古天庭执掌文理规矩、万灵生机演变的“文曲真君”。
  - **特色**：温和有度。笔迹如晕染的黑墨，热爱天地众生的抗争故事，在暗中指点沈渊寻找因果缝隙中的生机。
